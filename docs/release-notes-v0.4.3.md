# YZJ Bridge v0.4.3

## 新功能

- **WSS 入站图片/文件**：`websocket` / `both` 模式现在会真正接收图片和文件，下载到机器人工作区后随问题一起交给模型；纯 WSS 部署也能读图、读文档。
- **关闭思考**：DSH 思考强度新增 `off`，可在「AI 设置 → DSH → 思考强度 → 关闭思考（不推理）」选择，响应更快、更省 token。
- 新增 `defaults.ws_debug_frames`（默认 `false`）：排查 WSS 帧结构时可打开；开启会记录消息正文，排障后请关闭。

## 修复

- 修复给机器人勾选的 Skill「过一会自动被取消」：目录名与 `SKILL.md` 内 `name` 不一致时不再被当成未安装清理。
- 修复 WSS 模式下图片/文件消息只收到 `[图片]` / `[文件]:名字` 占位、模型读不到附件的问题（此前可能拿旧文件作答）。
- 附件下载失败（超限、类型拦截、网络错误）时会在回复中明确说明，不再静默跳过。

## 优化

- 新增 `yzj_cli.attachment` 配置：`files_enabled`、`file_max_mb`（默认 50）、`max_files`（默认 5）、`file_block_ext`（默认拦截可执行文件）。
- 附件下载与轮询解耦：纯 WSS 部署也生效；yzj-cli 未就绪时会告知模型附件不可用。

## 安装

下载并覆盖安装 `YZJBridge-0.4.3-Windows-x64-setup.exe`，重启桥服务。
